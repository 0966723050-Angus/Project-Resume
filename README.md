# ATK專案履歷(Project Resume)

手機友善的 RWD / PWA 網頁工具,直接編輯 Google 共用雲端硬碟「ATK」中的 `Project Resume.xlsx`。

## 功能

左上角 ☰ 選單:**專案履歷 / 殘件項目 / 設定**

### 權限
- 已建立的專案履歷/殘件只有**填表人**與**管理者**(`js/config.js` 的 `ADMINS`)可以修改、刪除;其他人開啟為唯讀(卡片上有 🔒)
- 填表人以 Google 帳號姓名/Email 記錄在 Excel「填表人」「填表人Email」欄;沒有記錄填表人的舊資料只有管理者能改
- 這是 App 內的限制;直接用 Excel 開檔仍依雲端硬碟的共用權限

### 專案履歷
- 首頁不列出已建立的履歷,只有查詢與新增:輸入專案代號/名稱(▾ 選單顯示「代號 名稱」)或作業日期起訖(有「今天」「本週」快捷鍵)後才顯示結果
- 「＋ 新增」→ 編輯頁。標題列顯示「日期 專案代號 專案名稱 專案履歷」,下方顯示填表人姓名
- 作業時間為日期 + 時(00~23)/分(每 5 分鐘)選單,24 小時制
- 「放棄編輯」(需確認):這次新建立的履歷 → 即使已儲存也從 Excel 刪除(連同由它轉出的殘件);既有履歷 → 放棄尚未儲存的修改
- 「刪除此專案履歷」只有管理者看得到
- 🔗 複製連結:剪貼簿內容為「日期 專案代號 專案名稱 專案履歷」+ 換行 + 連結(`…/#/v/<履歷編號>`,另含超連結格式,
  貼到 Outlook/Teams 會顯示為標題文字的連結)。連結開啟為**唯讀**檢視。尚未儲存時會先儲存
- 欄位
  - 專案代號 / 專案名稱:可手Key,或 ▾ 從清單選取(兩者連動)
  - 單元、專案階段:可手Key 或 ▾ 選取
  - 作業開始/結束時間:日期+時間選擇;報工時數空白時依起訖時間自動計算(可再修改)
  - 協同作業人員:清單複選(核取方塊)+ 下方手Key 其他人員(手Key 名單接在後面,以「、」分隔)
  - 圖片、附件:整份履歷共用,位於「工作內容」下方(Excel 只寫在該履歷第一列;舊資料若分散在各問題列,讀取時自動合併)
  - 每個問題:問題描述、發生原因、暫定對策、永久對策、處理結果、備註;「＋ 新增問題」可加第 2、3… 個問題
- 「轉殘件」鍵:勾選要轉出的問題(預設勾選尚未轉出且「處理結果」空白者),自動帶入日期/專案/問題描述/原因/對策(不帶圖片、附件),
  寫入「Remain Item」,並在履歷該問題標記「轉殘件 = V」

- 專案代號排序(所有選單、清單):前 2 碼相同的放一起(EQ→MD→ST→AF→其他),同類型依後段數字(年份 2 碼+流水號)由舊到新;
  Choice 工作表存檔時也依此排序

### 殘件項目
- 不列出全部殘件:從上方下拉選單選擇專案後才顯示該專案的殘件(可再依狀態篩選)
- 「＋ 新增殘件」、「⬇️ 匯出 Excel」(依目前選擇匯出 .xlsx,第一欄為「項次」,不含專案代號/名稱欄(已在標題),標題為「專案代號 專案名稱 殘件項目」;手機會開分享選單,可存到「檔案」)
- 欄位:日期、專案代號/名稱、問題描述、發生原因、暫定對策、永久對策、ECN(是/否)、權責區分、負責人(下拉選取)、
  改善期限、改善進度及結果、狀態(Open/Close)、附件、備註;從履歷轉入的會顯示來源連結

### 登入
- 此裝置登入過後會記住帳號與存取權杖:約 1 小時內重新開啟 App 直接進入,不需登入
- 權杖過期後,登入畫面顯示「繼續使用 xxx@…」或跳出「登入已逾時 → 繼續」,一鍵完成、不需再選帳號
  (Google 規定網頁的存取權杖最長約 1 小時,且瀏覽器只允許在點擊時開啟 Google 視窗,因此無法完全免點)
- 使用中權杖快到期時,會在使用者點擊時自動更新
- ☰ 選單底部可登出(會清除此裝置記住的帳號)

### 專案管理(只有管理者看得到、可編輯)
- 資料:共用雲端硬碟 ATK 的 `Project Management.xlsx`(也接受 `Project Managment.xlsx`)工作表「project list」,一列 = 一個專案批次
- 只有查詢與新增:輸入專案代號或專案名稱(模糊比對,忽略大小寫/空白/底線/連字號,多個關鍵字須全部出現)後才顯示結果;可勾「只看未結案」
- 欄位依 Excel:日期欄(需求日期、裝置構成表、長交期物料、圖面提交、製令開立、期限)用日曆;階段可手Key 或 ▾ 選取
  (清單存在 Project Resume.xlsx「Choice」的「管理階段」欄,可新增/刪除);狀態 Open/Close;結案 是/否;
  年度空白時依專案代號自動帶入(EQ-2260008 → 2026)
- 進度區塊:裝置構成表、長交期物料、圖面提交、製令開立、採購狀況、現地施工 都是「日期 + 狀態(未進行/進行中/延遲/已完成)」;
  狀態存在新欄「裝置構成表狀態…現地施工狀態」;「現地施工」日期也是新欄(第一次使用時一次接在最後一欄之後建立)
- 頁首儲存鍵旁「‹ ›」(上一個/下一個)依目前查詢結果的順序切換專案(專案履歷的編輯/唯讀頁也有)
- 「階段」位於進度區塊第一列
- 編輯頁上方「🧩 殘件項目(Open n / 共 m)」:依專案代號連到殘件項目頁(已選好該專案),殘件頁會出現「↩ 返回專案管理」回到原本那一筆
- 追蹤事項(追蹤確認事項/進度與結果/期限/狀態)一組一區塊,「＋ 新增追蹤事項」可加多組:第 1 組在原本 V~Y 欄,
  第 2 組起在 AE 欄之後新增「追蹤確認事項2/進度與結果2/期限2/狀態2」…(AB~AD 為表內既有輔助欄,不使用)
- 寫入方式:只修改有變動的儲存格(保留每列原有格式);新增接在最後一筆之下;刪除時下方各列上移;篩選範圍自動延伸

### 設定(只有管理者看得到)
- 帳號/檔案資訊、從雲端重新載入、在雲端硬碟開啟、登出
- 編輯下拉選單:專案代號/名稱、單元、專案階段、協同作業人員、負責人、權責區分(新增/刪除)。
  各欄位的 ▾ 選單中也可直接「＋ 加入」或「編輯清單」刪除。清單存在 Excel「Choice」工作表

### 分享連結免登入
- 連結格式 `…/#/v/<履歷編號>?k=<分享碼>`;分享碼存在 Excel「分享碼」欄(新履歷自動產生,舊履歷在第一次複製連結時補上)
- 未登入時經由 Google Apps Script 網頁應用程式(`gas/Code.gs`,以管理者身分執行)讀取 Excel,只回傳編號與分享碼都相符的那份履歷;
  圖片/附件也只限該履歷內列出的檔案
- 部署:script.google.com 新增專案 → 貼上 `gas/Code.gs` → 部署 → 網頁應用程式(執行身分:我;存取:所有人)→ 網址填入 `js/config.js` 的 `SHARE_URL`
- 已登入的人開啟連結時直接讀雲端硬碟
- 加速:index.html 一開啟就先送出 Apps Script 請求(不等其他程式);Apps Script 記住檔案 ID、每份履歷各自快取 6 小時,
  `installWarmTrigger` 建立每 10 分鐘預熱排程(檔案更新後自動重新解析)
- 免登入檢視字體放大、圖片不顯示「在雲端硬碟開啟」;網頁 `<title>` 留空、不放 description,貼到釘釘/LINE 的連結卡片不顯示多餘文字

## Excel 對應

| 工作表 | 說明 |
|---|---|
| Project Resume | 一列 = 一個問題。同一份履歷的多個問題共用 U 欄「履歷編號」;「報工時數」「工作內容」只寫在第一列(避免加總重複)。V 欄「轉殘件」、W「填表人」、X「填表人Email」、Y「分享碼」|
| Remain Item | 原有 A~N 欄,另新增 O「附件」、P「來源履歷」、Q「殘件編號」、R「填表人」、S「填表人Email」|
| Choice | 下拉選單清單(依第 1 列標題對應)|

- 缺少的欄位標題會在第一次儲存時自動補上
- 圖片/附件上傳到 Excel 同一資料夾下的「Project Resume 附件」資料夾,儲存格內每行一個「檔名 連結」;
  手機照片會縮到長邊 1600px。取消編輯時,這次剛上傳但未儲存的檔案移到垃圾桶
- 日期時間以 Excel 日期序號寫入(格式 `yyyy/mm/dd hh:mm`、`yyyy/mm/dd`)

## 寫入方式與多人同時使用

每次儲存都會**先下載雲端最新檔案**,只以「履歷編號 / 殘件編號」替換這次修改的那一筆,再上傳。
其他人同時新增或修改別筆資料不會被覆蓋。只重寫三張工作表的資料列,標題列、欄寬、凍結窗格、條件式格式等保持原樣。
直接在 Excel 手動輸入、沒有編號的列也可以讀取,第一次經由 App 存檔時會自動補上編號。
